Phase 7 — Circuit Breaker

Three States

CLOSED

Normal. All calls pass through. Failures increment counter.

OPEN

Fault. All calls rejected immediately. No timeout wait. Opens at fail_max failures.

HALF_OPEN

Testing. One call allowed. Success → CLOSED. Failure → OPEN.

State Transitions

CLOSED ──(fail_max consecutive failures)──→ OPEN
OPEN   ──(reset_timeout seconds elapsed)──→ HALF_OPEN
HALF_OPEN ──(test call succeeds)──────────→ CLOSED
HALF_OPEN ──(test call fails)─────────────→ OPEN

ChipMate settings: fail_max=3, reset_timeout=30s

pybreaker vs Manual (alternative1)

# pybreaker (resilience.py) — decorator pattern:
ollama_breaker = CircuitBreaker(fail_max=3, reset_timeout=30)

@ollama_breaker
def _call_ollama(prompt, context):
    # actual Ollama call
    ...

# Manual state machine (resilience_alternative1.py) — same logic, visible:
class ManualCircuitBreaker:
    def __init__(self, fail_max, reset_timeout):
        self._state = CircuitState.CLOSED
        self._failure_count = 0
        self._last_failure_time = 0.0

    @property
    def state(self):
        # Check OPEN -> HALF_OPEN transition on every access
        if self._state == CircuitState.OPEN:
            if time.time() - self._last_failure_time >= self.reset_timeout:
                self._state = CircuitState.HALF_OPEN
        return self._state

Why the Fallback Matters

Without a fallback, an open circuit returns an exception to the user. ChipMate's fallback returns the retrieved context directly with a disclaimer — always available, no LLM required. In production this could be a secondary model or a cached answer.

Demo: Triggering the Breaker

# Stop Ollama to simulate LLM failure:
pkill ollama
# Fire 4 calls — watch the breaker open on call 3:
python -c " from local.resilience import call_llm_with_fallback for i in range(4): answer, method = call_llm_with_fallback('What is voltage?', 'Context text') print(f'Call {i+1}: method={method} answer={answer[:50]}') "
# Expected output:
# Call 1: method=fallback (ConnectionError) # Call 2: method=fallback (ConnectionError) # Call 3: method=fallback (ConnectionError — breaker opens here) # Call 4: method=fallback (CircuitBreakerError — rejected instantly)
# Restart Ollama:
ollama serve &
# After 30s, breaker moves to HALF_OPEN and next call tests recovery
