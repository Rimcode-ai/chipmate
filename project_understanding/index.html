ChipMate — Project Understanding

Living reference for all design decisions, trade-offs, and implementation patterns. Updated as phases complete.

Architecture

User Query
    │
    ▼
[Router]  ← deterministic regex (no LLM call)
    │
    ├── spec_lookup ──→ [Retrieval]  pgvector + tsvector + RRF  ──┐
    │                                                               │
    └── relationship ──→ [Graph]    Neo4j Cypher / Neptune Gremlin ─┤
                                                                    │
                                                            [Analysis]  Ollama / Bedrock
                                                                    │
                                                            [Grounding]  regex extraction + source check
                                                                    │
                                            confidence >= 0.6 ─→ [END: Return answer]
                                            confidence < 0.6  ─→ [Human Approval] ─→ [END]

Phases

Phase 1

Structure-Aware PDF Chunking

Split on section headers, keep tables intact, tag metadata.

ingest.py ingest_alternative1.py ingest_alternative2.py
Phase 2

Hybrid Search (Vector + BM25 + RRF)

pgvector cosine + Postgres FTS, fused with Reciprocal Rank Fusion.

retrieve.py retrieve_alternative1.py retrieve_alternative2.py embed.py embed_alternative1.py
Phase 3

Component Relationship Graph

Neo4j Cypher locally. Neptune Gremlin on AWS. Same interface, different backend.

graph.py graph_alternative1.py aws/graph_neptune.py
Phase 4

LangGraph Multi-Agent

StateGraph with conditional routing. Deterministic router, provider-agnostic LLM call.

agent.py agent_alternative1.py aws/agent_aws.py
Phase 5

Deterministic Evaluation

Regex extraction from answers verified against retrieved source text.

eval.py eval_alternative1.py golden_dataset.json
Phase 6

FastAPI + Redis Rate Limiting

Sliding window rate limiter. MD5-key semantic cache. Async endpoint.

main.py main_alternative1.py aws/lambda_api.py
Phase 7

Circuit Breaker

pybreaker wraps the LLM call. Three states: CLOSED, OPEN, HALF_OPEN.

resilience.py resilience_alternative1.py aws/resilience_aws.py
Phase 8

Observability

Langfuse locally. X-Ray + CloudWatch on AWS. One span per agent node.

tracing.py tracing_alternative1.py aws/tracing_aws.py
Phase 9

Load Testing

Locust with mixed task weights. Record RPS, p95 latency, failure rate.

locustfile.py aws/locustfile_aws.py
