Phase 9 — Load Testing

Key Metrics to Record

MetricWhat it meansHow to find it in Locust
RPSRequests per second at peak loadLocust terminal: "Requests/s" column
Median latency50th percentile — typical user experience50%ile column
p95 latency95% of requests finish in this time or less95%ile column
Failure rate% of requests returning non-2xx"Failures/s" / "Requests/s"

Expected Bottleneck

Local (Ollama CPU):
  Ollama inference: ~2-5s per query on M-series Mac, ~10-30s on Intel
  Retrieval + DB:   ~100-200ms
  API overhead:     ~5ms
  → Bottleneck: LLM inference
  → RPS will be low (0.5-2 req/sec per user)

AWS (Bedrock + Aurora Serverless):
  Bedrock Haiku:    ~0.5-1.5s per query (GPU inference)
  Aurora cold:      ~200-500ms (Serverless v2 cold start)
  Aurora warm:      ~20-50ms
  → Bottleneck: Bedrock inference (still, but faster)
  → RPS better (~2-5 req/sec per user)

Locust Task Weights

@task(7)   # 70% of traffic: spec queries (most common)

@task(3)   # 30% of traffic: relationship queries
def relationship_query(self): ...

@task(1)   # occasional health checks
def health_check(self): ...

Run Commands (Local)

# Make sure the API is running:
uvicorn local.main:app --port 8000
# In another terminal:
mkdir -p results
locust -f locustfile.py \ --host http://localhost:8000 \ --users 20 --spawn-rate 5 \ --run-time 2m --headless \ --csv results/load_test_local
cat results/load_test_local_stats.csv
AWS cost warning: Each Locust request to API Gateway calls Bedrock. Keep --users 10 and --run-time 2m maximum. ~120 Bedrock calls at Haiku rates = ~$0.01-0.02. Check Cost Explorer after.

Run Commands (AWS)

locust -f aws/locustfile_aws.py \ --host https://YOUR_API_ID.execute-api.us-east-1.amazonaws.com \ --users 10 --spawn-rate 2 \ --run-time 2m --headless \ --csv results/load_test_aws
Interview talking point: "I ran a load test with Locust. Local numbers: X req/sec, Y ms median, Z ms p95. AWS Bedrock numbers: [your numbers]. The bottleneck in both cases is LLM inference — retrieval and API layers add under 200ms total. I can show you the CSV output."
